# SafeLendingPool invariant scaffold (lending)

Generated by foundry-invariant-kit. This is a starting point for your own
invariant testing. It is not a guarantee of correctness or security. Passing
these properties does not mean the contract is safe; review every property,
fix the TODOs, and add properties specific to your protocol.

Files:
- `SafeLendingPoolHandler.sol`: bounded fuzz actions (bound(), vm.prank, actors, ghost variables)
- `SafeLendingPoolInvariant.t.sol`: the invariant properties
- `SafeLendingPoolAsset.sol`: minimal mintable mock used as the underlying asset

Properties:
- (experimental) total borrows <= total deposits
- (experimental) cash + borrows cover deposits
- (experimental) a successful borrow/withdraw leaves the account within LTV (health hook)
- (experimental) every tracked actor stays healthy (no prices/interest in the harness)
- (experimental) repay never increases debt
- (experimental) repay never credits more than the pool received
- (experimental, if liquidate exists) liquidation only succeeds on unhealthy positions

Run: `forge test --match-contract SafeLendingPoolInvariantTest`
Suggested foundry.toml: `[invariant] runs = 64, depth = 64, fail_on_revert = false`

Tracked holders only: sum and balance checks see the tracked actors, the test contract and the handler.
Balances or shares held at any other address are invisible to them; add those holders yourself.

Warnings from generation:
- lending is EXPERIMENTAL: actions are inferred from names; review the account-health hook
- account-health hook wired from collateralOf(address)/debtOf(address); values are compared 1:1 with LTV from pool.ltvBps(), check this matches your protocol
