# SafeVault invariant scaffold (erc4626)

Generated by foundry-invariant-kit. This is a starting point for your own
invariant testing. It is not a guarantee of correctness or security. Passing
these properties does not mean the contract is safe; review every property,
fix the TODOs, and add properties specific to your protocol.

Files:
- `SafeVaultHandler.sol`: bounded fuzz actions (bound(), vm.prank, actors, ghost variables)
- `SafeVaultInvariant.t.sol`: the invariant properties
- `SafeVaultAsset.sol`: minimal mintable mock used as the underlying asset

Properties:
- convertToShares/convertToAssets round trip never favors the user
- previewDeposit <= shares minted (and the other previews are conservative)
- no shares are minted for zero assets
- deposit then redeem cannot profit
- solvency: vault asset balance >= previewRedeem(totalSupply)
- vault asset balance covers totalAssets
- totalSupply equals the sum of tracked share balances

Run: `forge test --match-contract SafeVaultInvariantTest`
Suggested foundry.toml: `[invariant] runs = 64, depth = 64, fail_on_revert = false`

Tracked holders only: sum and balance checks see the tracked actors, the test contract and the handler.
Balances or shares held at any other address are invisible to them; add those holders yourself.
